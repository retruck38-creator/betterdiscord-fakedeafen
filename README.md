<a name="english"></a>
## English

Simple BetterDiscord plugin that keeps incoming audio active while showing deafened status to others.

### Installation

1. Download `FakeDeafen.plugin.js`
2. Move the file into your BetterDiscord plugins folder:
   - Windows: `%appdata%\BetterDiscord\plugins`
   - Linux: `~/.config/BetterDiscord/plugins`
   - Mac: `~/Library/Application Support/BetterDiscord/plugins`
3. Enable **FakeDeafen** in Discord Settings -> Plugins.

### How to use

Just click the regular deafen button in Discord. Others will see you as deafened, but you will still hear incoming audio.

<a name="русский"></a>
## Русский

Плагин для BetterDiscord. Показывает статус "заглушен" для остальных пользователей, но оставляет входящий звук в динамиках.

### Установка

1. Скачай файл `FakeDeafen.plugin.js`
2. Перетащи его в папку плагинов BetterDiscord:
   - Windows: `%appdata%\BetterDiscord\plugins`
   - Linux: `~/.config/BetterDiscord/plugins`
   - Mac: `~/Library/Application Support/BetterDiscord/plugins`
3. Включи **FakeDeafen** в Настройках Discord -> Плагины.

### Использование

Нажми стандартную кнопку наушников в Дискорде. Для всех в канале ты будешь висеть в муте, но звук продолжит идти.
